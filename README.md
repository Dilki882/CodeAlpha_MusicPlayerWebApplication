🎵 PULSE MUSIC — Modern Music Player

Pulse Music is a modern, responsive, and interactive music player web application built using HTML5, CSS3, and Vanilla JavaScript.

The application provides a complete music-streaming-style experience with music discovery, audio playback, favorites, playlists, recently played songs, search, queue management, themes, and responsive navigation.

«🎧 Feel the rhythm. Live the moment.»

✨ Features

- ▶ Play / Pause

- ⏭ Next song

- 🔁 Repeat All

- 🔇 Mute / Unmute

🔍 Music Discovery

❤️ Personal Library

🚀 How to Run

Option 1 — Open Locally

1. Download or clone this repository.
2. Make sure the "images" and "songs" folders are inside the project folder.
3. Make sure the file names in "script.js" exactly match the uploaded image and audio files.
4. Open "index.html" in a modern web browser.
5. Start exploring the music player.

Option 2 — GitHub Pages

The project can also be hosted using GitHub Pages.

After enabling GitHub Pages for the repository, the website can be accessed through the generated GitHub Pages URL.

⌨️ Keyboard Controls

Key| Action
"Space"| Play / Pause
"Arrow Right"| Forward 5 seconds
"Arrow Left"| Backward 5 seconds
"Arrow Up"| Increase volume
"Arrow Down"| Decrease volume
"Escape"| Close queue / modal
